# BANANA Animation Studio

The uploaded banana MASTER is treated as the visual source of truth. Open `tools/animation-studio.html` through GitHub Pages.

## Rules
- 48×48 logical pixels
- Palette locked to black / banana yellow / brown / white
- Face, stem and core body are MASTER LOCKED
- Only limb/lower-body motion zones are editable
- 8 walk frames with live preview
- Export produces `banana-walk.json`

The game should consume approved animation data; do not redraw the character independently.
